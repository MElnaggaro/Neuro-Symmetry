# Neuro-Symmetry MVP

Browser-first starter for a real-time facial asymmetry demo.

## Files

- `index.html` - app shell and media scripts
- `app.js` - webcam, landmark processing, scoring, and calibration
- `style.css` - visual layout and dashboard styling

## Run

Open `index.html` through a local server so camera permissions work correctly.

Example:

```bash
npx serve neuro-symmetry-mvp
```
